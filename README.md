# 🚦 Real-Time Helmet Violation Detection System

A Computer Vision-based project that detects motorcycle riders and identifies whether they are wearing helmets in real time using YOLOv5 and OpenCV.

## 📖 Overview

Road safety is a major concern, and helmet compliance is one of the most important factors in reducing motorcycle-related injuries. This project automatically detects motorcycle riders and checks whether they are wearing helmets using Deep Learning and Computer Vision techniques.

The system can process live webcam feeds, CCTV footage, or recorded videos and highlight helmet violations in real time.

---

## ✨ Features

- Real-time rider detection
- Helmet / No Helmet classification
- Live webcam support
- Video file processing
- Real-time bounding box visualization
- Violation detection and monitoring
- Fast inference using YOLOv5
- Easy deployment using Python

---

## 🛠️ Tech Stack

- Python 3.10
- YOLOv5
- OpenCV
- NumPy
- Pandas
- Tkinter

---

## 🔍 How It Works

1. Capture video from webcam or video file.
2. Detect motorcycle riders using YOLOv5.
3. Detect whether the rider is wearing a helmet.
4. Classify the rider as:
   - Helmet ✅
   - No Helmet ❌
5. Display results with bounding boxes and labels.
6. Generate logs for detected violations.
